# ⭐ **LOGICAL ADDRESS (80386 / Pentium)**

### **Definition:**

A **Logical Address** is the address generated by the CPU when a program accesses memory.  
It has **two parts**:

```
Logical Address = Segment Selector : Offset
```

### **Components:**

1. **Segment Selector (16 bits)**  
    Contains:
    
    - **Index (13 bits)** → selects descriptor from GDT/LDT
        
    - **TI (1 bit)** → GDT(0) or LDT(1)
        
    - **RPL (2 bits)** → privilege request
        
2. **Offset (up to 32 bits)**
    
    - Specifies the location inside the segment
        
    - Comes from IP/EIP, SI, DI, BP, SP, or addressing modes
        

### **Key Points:**

- Does **NOT** contain the physical or base address.
    
- Selector chooses the **descriptor**, not the segment itself.
    
- Used only as **input** to the segmentation unit.
    
- Cannot be sent directly to RAM.
    

### **Purpose:**

➡ Programming convenience  
➡ Allows segment-based memory access  
➡ Supports protection using privilege levels

# ⭐ **LINEAR ADDRESS (80386 / Pentium)**

### **Definition:**

A **Linear Address** is the **32-bit address** produced after **segmentation**.

It is formed as:

```
Linear Address = Base Address (from descriptor) + Offset
```

### **How it is created:**

1. CPU reads **Selector** → finds descriptor in GDT/LDT
    
2. Descriptor provides **Base address** (32-bit)
    
3. CPU adds **Offset** from instruction
    
4. Result = **Linear Address**
    

### **Range:**

`0x00000000` to `0xFFFFFFFF`  
(4 GB linear address space)

### **Key Points:**

- Linear Address is the **real 32-bit flat address** used by paging.
    
- If **paging OFF** → Linear Address = Physical Address
    
- If **paging ON** → Linear Address is translated to a **Physical Address** using page tables.
    

### **Purpose:**

➡ Provides a large flat 4GB address space  
➡ Used as the “virtual address” in virtual memory systems  
➡ Separates segmentation from paging

---

# ⭐ **RELATION BETWEEN THE TWO**

```
Logical Address (Selector:Offset)
           ↓ Segmentation
Linear Address (Base + Offset)
           ↓ Paging
Physical Address (RAM)
```

### ✔ Logical Address → for segmentation

### ✔ Linear Address → for paging & virtual memory

### ✔ Physical Address → actual RAM

# ⭐ SUPER SHORT SUMMARY FOR EXAMS

### **Logical Address**

- Format: **Selector : Offset**
    
- Selector chooses descriptor (not base)
    
- Used by program and segmentation unit
    

### **Linear Address**

- 32-bit address after segmentation
    
- Formed as **Base + Offset**
    
- Input to paging
    
- Also called **Virtual Address** (in paging systems)
